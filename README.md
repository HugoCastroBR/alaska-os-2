# alaska-os-2

Alaska OS 2 – Web OS monorepo scaffolded with TypeScript, Vite, ESLint, and Prettier.

## Project structure

- `apps/web` – desktop web client
- `packages/` – shared logic and future modules

## Getting started

```bash
npm install
npm run dev --workspace apps/web
```

## Scripts

- `npm run dev` – starts the web desktop
- `npm run build` – builds the web app for production
- `npm run lint` – runs ESLint
- `npm run format` – formats files with Prettier
- `npm run typecheck` – validates TypeScript across the repo
